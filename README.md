# Titanic Survival Prediction using Machine Learning 🚢

## Overview

This project uses Machine Learning techniques to predict whether a passenger survived the Titanic disaster based on various passenger attributes such as age, gender, ticket fare, passenger class, and family relationships.

The project focuses on data preprocessing, handling missing values, feature engineering, model training, and classification using Logistic Regression.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

---

## Dataset

The dataset contains passenger information including:

- Passenger Class (Pclass)
- Sex
- Age
- SibSp
- Parch
- Fare
- Embarked
- Survival Status

---

## Project Workflow

1. Loaded the Titanic dataset
2. Explored and analyzed the data
3. Visualized missing values using a heatmap
4. Handled missing values in the dataset
5. Encoded categorical features
6. Selected important features for training
7. Split the dataset into training and testing sets
8. Trained a Logistic Regression model
9. Generated survival predictions
10. Evaluated model performance

## Model Used

Logistic Regression was used as the classification algorithm to predict passenger survival based on selected features.
